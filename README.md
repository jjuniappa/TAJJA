# Number Duel

숫자 카드 1~9를 사용해 AI와 대결하는 간단한 웹 카드 게임입니다.

## 규칙

- 플레이어와 AI는 각각 1~9 카드 한 장씩을 가집니다.
- 한 번 사용한 카드는 다시 사용할 수 없습니다.
- 더 큰 숫자가 승리합니다.
- 패자는 두 카드 숫자의 차이만큼 에너지를 잃습니다.
- 단, 1은 9를 이깁니다.
- 에너지는 각각 20으로 시작합니다.
- 한쪽 에너지가 0이 되거나 모든 카드를 사용하면 게임이 종료됩니다.

## 실행

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

GitHub Pages를 사용할 경우 저장소의 Settings → Pages에서 배포할 브랜치를 선택하세요.

## 파일

- `index.html`: 게임 화면 구조
- `style.css`: 레이아웃, 카드, 에너지바, 반응형 디자인
- `script.js`: 카드 선택, AI 랜덤 선택, 승패 및 에너지 계산
- `assets/game-scene.png`: 배경 + AI 캐릭터 + 테이블 통합 이미지

## 카드 이미지 에셋

`assets/cards/` 폴더에 실제 카드 이미지가 포함되어 있습니다.

- `1.png` ~ `9.png`: 카드 앞면
- `back.png`: 카드 뒷면

테이블 위 공개 카드와 화면 하단 선택 카드 모두 이 이미지 파일을 사용합니다.


## 상황별 장면 변경

- `assets/game-scene.png`: 기본 및 무승부 장면
- `assets/game-scene-ai-win.png`: AI가 이겼을 때 기뻐하는 장면
- `assets/game-scene-ai-lose.png`: AI가 졌을 때 화난 장면

각 라운드의 승패와 최종 결과에 따라 반응 이미지가 표시되며, 약 3초 뒤 기본 이미지로 자동 복귀합니다.
